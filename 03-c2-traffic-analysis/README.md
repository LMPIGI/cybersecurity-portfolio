# Project 03 - Meterpreter C2 Traffic Analysis

**Date:** 2026-06-06  
**Tools:** Wireshark, Metasploit, msfvenom  
**Environment:** Kali Linux (attacker) -> Windows 10 (victim), isolated host-only network

---

## Objective
Capture and analyse the live network traffic generated by a Meterpreter reverse shell session, identifying the command and control (C2) communication pattern at the packet level.

---

## Methodology

### 1. Setup
- Wireshark capturing on Ethernet0 (victim interface) before backdoor execution
- Meterpreter listener running on Kali at 192.168.44.129:4444
- backdoor.exe delivered and executed on Windows victim

### 2. Capture
- Filter applied: `ip.addr == 192.168.44.129 && tcp.port == 4444`
- 499 packets captured on port 4444
- Total C2 conversation size: 555 KB

---

## Findings

### TCP handshake - packet 719
| Field | Value |
|-------|-------|
| Source IP | 192.168.44.128 (victim) |
| Destination IP | 192.168.44.129 (Kali) |
| Source Port | 57677 |
| Destination Port | 4444 |
| Flag | SYN - connection initiation |

### TCP stream analysis
Following the TCP stream revealed:
- Windows PE executable header visible at stream start ("This program cannot be run in DOS mode") - this is the Meterpreter stage being delivered from Kali to Windows
- 555 KB of encrypted C2 communications between attacker and victim
- Large data transfers (Len=1460) representing Meterpreter commands and responses

---

## Forensic Significance

| Indicator | Significance |
|-----------|-------------|
| Outbound connection to port 4444 | Default Metasploit port - immediate red flag |
| PE header in TCP stream | Executable code delivered over network - fileless staging |
| 555 KB encrypted traffic | Active C2 session with command exchange |
| Persistent ESTABLISHED connection | Backdoor maintaining contact with attacker |

---

## Key forensic takeaway
Even though Meterpreter traffic is encrypted, the following indicators are still visible in a packet capture and would alert an analyst:
- The destination port (4444)
- The volume and pattern of traffic
- The PE header at the start of the stream
- The persistent ESTABLISHED connection to an unknown external IP

A PCAP file is one of the most powerful forensic artefacts available during incident response - it allows complete reconstruction of network activity even after the attacker has disconnected.
